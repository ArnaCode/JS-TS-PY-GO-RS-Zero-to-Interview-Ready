# 019 Remove Falsy Values

**Challenge**

Filter out falsy values from an array.

### Input

- JavaScript & TypeScript
- [0, 1, false, 2, "", 3, null, undefined]

- Python
- [0, 1, False, 2, "", 3, None]

- Go
- [0, 1, false, 2, "", 3, nil]

- Rust
- [0, 1, false, 2, "", 3, Null]

### Output

- [1, 2, 3]
